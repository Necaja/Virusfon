# Вирусфон Навсегда — Android-проект для ремейка

Исходник: J2ME-игра *«Вирусфон Навсегда»* (автор king86, перевод forum.fonzo.ru), 240×320, CLDC-1.0 / MIDP-1.0 + Nokia UI API.

Этот проект — **шаг 1**: игра декомпилирована, очищена от артефактов декомпилятора и обёрнута в слой
совместимости J2ME → Android, чтобы её можно было запустить «как есть» и дальше постепенно
переписывать в нормальный Android-код.

## Что внутри

| Путь | Что это |
|---|---|
| `app/src/main/java/main/` | Код игры (бывший пакет `main`): `f` — Canvas + главный цикл и меню, `d` — сущности (герой/враги/NPC), `e` — данные, скрипты, диалоги, `a` — камера/карты, `b` — бонус-магазин, `c` — анимация-спрайт, `cMIDlet` — точка входа |
| `app/src/main/java/engine/` | Библиотека движка (бывший пакет `a`, **переименован** — см. ниже): `c` — тайловые карты, `d` — текст/диалоги/меню, `f` — MIDI-плеер, `h` — графические утилиты, `a` — ГСЧ, `b` — бывший SMS-биллинг, `e` — чтение big-endian из потока, `g` — общий шрифт |
| `app/src/main/java/javax/microedition/**`, `com/nokia/mid/ui/**` | Слой совместимости J2ME (Canvas, Graphics, Image, Font, Display, MIDlet, RecordStore, Player, Nokia DirectGraphics) поверх `android.graphics` |
| `app/src/main/java/compat/` | Android-хост: `GameActivity`, `GameView` (кадр 240×320 + экранные кнопки), `Res` (чтение из assets) |
| `app/src/main/assets/` | Все ресурсы из JAR без изменений: 110 PNG, 42 `p*.DAT` (карты), 43 `*.bin` (скрипты уровней и анимации), 2 MIDI |
| `docs/ANALYSIS.md` | Разбор архитектуры, форматов данных и план ремейка |
| `docs/decompiled-cfr/` | «Сырой» вывод CFR (оригинальные имена пакетов, не компилируется) — для сверки |
| `docs/original-meta/MANIFEST.MF` | Манифест исходного JAR |
| `tools/check-compile.sh` | Проверка компиляции без Android SDK (на заглушках `tools/androidstubs`) |

## Сборка

Нужны Android Studio (Koala+) или Android SDK + JDK 17.

```
./gradlew assembleDebug      # APK: app/build/outputs/apk/debug/
```

Или просто откройте папку в Android Studio. AGP 8.7.3, Gradle 8.9, compileSdk/targetSdk 35, minSdk 21.

> ⚠️ В среде, где готовился проект, не было Android SDK и доступа к Google Maven, поэтому **APK не собирался и на
> устройстве не запускался**. Проверена только компиляция всего Java-кода на заглушках Android API
> (`tools/check-compile.sh`). Возможны мелкие несостыковки при первой сборке — пришлите лог, поправим.

## Горизонтальный широкий экран
Игра запускается в альбомной ориентации. Высота исходного кадра (320) растягивается на всю высоту экрана, а в стороны
игра **дорисовывает мир**: карту, задник, спрайты и врагов (до +240 px логического экрана с каждой стороны, всего ширина до 720).

Как устроено:
* `Display.setLogicalWidth(w)` — логическая ширина кадра; `engine.View` — `extra()` (добавка с каждого бока) и `right()`.
* Весь интерфейс игры по-прежнему верстается в центральной области 240×320 (она центрируется автоматически).
  Всё, что игра рисует «на весь экран» (`setClip/fillRect(0,*,240,*)`, затемнения), `Graphics` сам растягивает на всю ширину.
* `engine/c.java` — карта рисуется шире; за краем карты тайлы отражаются зеркально, задник достраивается зеркальными копиями.
* `main/d.java` — видимость/активация/появление врагов учитывает боковые поля.
* Экраны интерфейса (меню, заставки): поля по бокам — размытое затемнённое продолжение центра (`Display.extendSides`).
* Портрет героя и шкалы привязаны к левому краю экрана, подписи софт-клавиш — к краям.

## Сенсорное управление (вариант «поверх кадра», как в Dead Cells)
Слева ◄ ► ▲ ▼, справа большая **АТАКА** (fire/OK) и **ПРЫЖОК** (= «вверх»), над ними навыки **1·3·7·9** (как на панели игры),
вверху справа **❚❚** (пауза = левая софт-клавиша «Меню»), **ИНФО** (правая софт-клавиша, вкладка «Инфо») и **123** (цифровая панель 0 2 4 5 6 8 * #). Мультитач; палец можно переводить между кнопками.
Раскладка — в `compat/GameView.java` (`onSizeChanged`, единица `u = высота/10`).
Аппаратные клавиши: стрелки/Enter, цифры, `Back` = правая софт-клавиша (-7), `Menu` = левая (-6).

## Отладка без Android (JDK достаточно)
`tools/desktop-harness/run.sh "8:-6,5:-5,18:-5" 711` запускает игру на обычной JVM, «нажимает» клавиши по состояниям и
сохраняет кадры в PNG (`/tmp/frames`). Удобно проверять отрисовку без телефона. `JAVA_OPTS="-Djump=101"` — сразу загрузить уровень.

## Автосборка APK без Android Studio
Залейте папку проекта в GitHub-репозиторий — `.github/workflows/build-apk.yml` соберёт debug-APK,
скачать его можно во вкладке Actions → Artifacts (`virusphone-debug-apk`).
